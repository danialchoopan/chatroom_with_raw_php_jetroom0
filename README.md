# جتروم (JetRoom) - سیستم چت پیشرفته با PHP خام

این پروژه یک بازنویسی کامل از سیستم چت قدیمی است که اکنون با معماری شی‌گرا (OOP) و الگوی MVC طراحی شده است. تمرکز اصلی در این نسخه بر امنیت بالا، رابط کاربری مدرن و قابلیت‌های پیشرفته بوده است.

## قابلیت‌های کلیدی

۱. سیستم ۱۰ چت‌روم موضوعی ثابت (عمومی، برنامه‌نویسی، سرگرمی و غیره).
۲. قابلیت ارسال پیام خصوصی (PV) با کلیک روی نام کاربری افراد.
۳. پشتیبانی از ارسال عکس در چت‌روم‌ها و پیام‌های خصوصی.
۴. رابط کاربری مدرن دو ستونه شبیه به دیسکورد با استفاده از Tailwind CSS محلی.
۵. به‌روزرسانی خودکار پیام‌ها با استفاده از JavaScript Fetch API بدون نیاز به رفرش صفحه.
۶. پشتیبانی از دیتابیس‌های MySQL و SQLite.

## راهنمای نصب و راه‌اندازی

### نیازمندی‌ها
- PHP 7.4 یا بالاتر
- اکستنشن PDO و PDO_SQLite یا PDO_MySQL

### مراحل نصب
۱. محتویات پروژه را در دایرکتوری وب‌سرور خود (مانند htdocs در XAMPP) قرار دهید.
۲. فایل `app/Config/config.php` را باز کرده و تنظیمات دیتابیس را انجام دهید.
   - برای استفاده از SQLite، مقدار `DB_TYPE` را روی `sqlite` بگذارید.
   - برای استفاده از MySQL، مقدار را روی `mysql` تنظیم کرده و اطلاعات سرور را وارد کنید.
۳. پوشه `public` را به عنوان Root وب‌سرور خود تنظیم کنید یا به آدرس `localhost/public` بروید.
۴. سیستم در اولین اجرا به صورت خودکار جداول مورد نیاز را در دیتابیس ایجاد می‌کند.

### کوئری‌های دیتابیس (در صورت نیاز به ساخت دستی)
تمامی دستورات ساخت جداول در فایل `database.sql` موجود است.

## امنیت
- جلوگیری از SQL Injection با استفاده از Prepared Statements در تمام کوئری‌ها.
- جلوگیری از XSS با فیلتر کردن تمامی خروجی‌ها در لایه نمایش.
- امنیت پسورد با الگوریتم password_hash.
- امنیت آپلود با بررسی Mime-Type، پسورد و تغییر نام رندوم فایل‌ها.
